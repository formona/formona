## 2. 앱 목적 재정의

다만, 해당 앱의 핵심 목적을 아래와 같이 재정리하여 전달드립니다.

```
앱으로 측정
      ↓
측정된 황금비율 값을 기반으로 제형틀 제작
      ↓
개인 맞춤 제형틀 제작을 위한 수치 데이터 확보
```

### 중요 포인트

- 수치 데이터의 목적은 **사용자(User)가 아닌 사측(포모나)**에 있습니다
- 앱 화면에 수치를 표기하는 이유는 **보여주기식 UI** 입니다
- 핵심은 측정된 수치를 **데이터로 수집 및 전달받을 수 있는 구조**가 필요합니다

---

## 3. 앱 기능 관련 문의

### 출력 수치 항목

- 출력 수치 항목이 전부 표시되지 않는 이유가 궁금합니다
- 확인 및 원인 공유 부탁드립니다

### SP / HP / EP 계산 기준

- 전달드린 MD 파일의 황금비 기준점 3선 정의대로 계산이 이루어지고 있는지 확인 부탁드립니다
- **첨부된 A 이미지 참고하여 확인 요청드립니다**

---

## 4. AR 미리보기 관련 문의

### Point 점 처리

- 현재 화면에 표시되는 랜드마크 point 점들을 **숨김 처리**하는 것이 가능한지 확인 부탁드립니다

### 황금비 기준점 3선 표시

- AR 미리보기 화면에 황금비 기준점 3선 (SP / HP / EP) 라인 표시가 가능한지 확인 부탁드립니다
- **첨부된 A 이미지 참고하여 확인 요청드립니다**

### AR 미리보기 처리 방향 제안

- 위 두 가지가 현재 버전에서 구현이 어렵다면
- AR 미리보기 기능은 **다음 버전(v2.0)으로 미루고**
- 현재 버전에서는 **숨김 처리 또는 제거**하는 방향을 제안드립니다
